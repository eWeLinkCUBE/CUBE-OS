# eWeLink CUBE OS

一套免费的本地自托管软件系统，将 eWeLink Wi-Fi 设备和多品牌 Zigbee 设备桥接到 Matter 网络，支持 Apple Home、SmartThings、Google Home、Alexa、Home Assistant 等平台。


# 🌐 项目简介

eWeLink CUBE OS 是一套免费开放、可自行部署的本地软件系统，用来升级家中的智能设备。  
<p align="center">
  <img src="https://raw.githubusercontent.com/eWeLinkCUBE/CUBE-OS/master/assets/CUBEHERO.png" alt="eWeLink CUBE OS" width="70%">
</p>

它能够让大量 eWeLink support 的 Wi-Fi 设备（例如 SONOFF 设备）在无需额外硬件的情况下，直接桥接到 Matter 网络，从而同时接入 Apple Home、SmartThings、Google Home、Amazon Alexa、Home Assistant 等平台和 App 使用。

配合一个 Zigbee dongle，eWeLink CUBE OS 还可以接入多品牌的 Zigbee 开关、传感器、灯具，并同样桥接到这些 Matter 平台，让不同来源的设备统一加入你的家庭系统。

通过安装 eWeLink CUBE OS，你可以让现有的 Wi-Fi 与 Zigbee 设备获得更现代、更统一的 Matter 智能家居体验，无需更换任何硬件。


# ⚡ 快速开始

> **3 分钟完成安装 — 无需编程。**

**1.** 为你的设备下载镜像文件 → [**⬇️ Latest Release**](https://github.com/eWeLinkCUBE/CUBE-OS/releases/latest)

**2.** 按照安装指南快速安装 — Windows 和 Mac 提供一键安装

**3.** 打开浏览器访问管理界面，开始添加设备

📖 **详细教程：**[cube.ewelink.cc/getting-started/quickstart](https://cube.ewelink.cc/getting-started/quickstart)


# 🚀 核心特性

### **1. 升级现有设备 — 无需购买新硬件**  
将大量 eWeLink/SONOFF Wi-Fi 设备和多品牌 Zigbee 设备（通过 Zigbee dongle）桥接到 Matter 网络，兼容主流智能家居平台。

### **2. Zigbee 设备零配置接入**  
插入 Zigbee dongle，即可快速添加各品牌的开关、传感器和灯具。自动发现、自动配对、即刻可用。

### **3. 多平台同时使用**  
桥接后的设备可同时出现在 Apple Home、SmartThings、Google Home、Amazon Alexa、Home Assistant 及其他 Matter 平台中。

### **4. 本地优先，快速稳定**  
完全运行在本地硬件上 — 响应快、连接稳定、不依赖云端。


# 💻 3 分钟完成安装 — 无需编程

eWeLink CUBE OS 提供开箱即用的镜像文件和虚拟机文件。  
只需烧录或导入即可 — 无需编程，无需复杂命令。  
任何人都能轻松完成安装。

你可以在以下设备上安装 eWeLink CUBE OS：

- **Raspberry Pi** — 低功耗、稳定，适合 24 小时运行  
- **NAS 设备** — 包括群晖、威联通等支持虚拟化的 NAS  
- **闲置旧电脑或笔记本** — 只要能运行虚拟机，就能运行 CUBE OS  
- **迷你主机、NUC、家庭服务器、工控机** — 适合对性能有更高要求的场景  

总之，几乎任何能运行虚拟机或 Linux 镜像的设备，都可以安装 eWeLink CUBE OS。
